## About me
My tastes in software are perhaps a bit overboard, but generally falls in line with [suckless](https://suckless.org/rocks/) and [cat-v](https://harmful.cat-v.org/software/). In general, I definitely use my computer like a madman, however my regular setup isn't as extreme since it has to balance between what I like and what is realistic:
- **OS(s)**: Linux (custom distro from scratch bootstrapped to have *almost* zero GNU software), OpenBSD, NetBSD, 9front, MacOS/OSX (Hackintosh), etc.
- **DE/WM**: unpatched dwm (Xlibre)
- **Editor/IDE**: [vis](https://github.com/martanne/vis), but vim for LaTeX editing
- **Browser**: Librewolf / Brave Origin (used to use qutebrowser, I use [runimage](https://github.com/VHSgunzo/runimage) on my setup to make sure I never actually install r*st on it)
- **Languages**: C (primary), **x86** ASM (specifically, I've learned the AT&T syntax), FORTH, Golang (beginner), Python (unfortunately), Java (unfortunately), etc.

Interesting fact: On the languages front, I am actually officially certified in Python and Java. Additionally, I'm also qualified and certified for Cybersecurity and IT.
